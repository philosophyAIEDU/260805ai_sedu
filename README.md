# 내 이야기 만들기 — 재활학교(특수학교) 학생을 위한 AI 창작 웹앱

학생이 **고르기만 하면** 자기 이야기로 그림 · 노래 · 영상 · 그림책이 만들어지는 정적 웹앱입니다.
글을 길게 쓰지 않아도 되고, 모든 단계는 큰 카드를 누르는 "선택"으로 진행됩니다.

---

## 1. 빠르게 시작하기

### 1) 파일 받기

```bash
git clone <이 저장소 주소>
cd 260805ai_sedu
```

### 2) 실행하기 (로컬 서버 권장)

별도의 서버 프로그램이나 빌드 과정이 필요 없습니다. 다만 브라우저 보안 정책(CORS) 때문에
**`index.html`을 더블클릭해서 여는 방식(`file://`)은 권장하지 않습니다.** 아래처럼 간단한
정적 서버로 열어 주세요. (파이썬은 대부분의 맥/리눅스에 이미 들어 있습니다.)

```bash
# 파이썬이 있을 때
python3 -m http.server 8000

# Node.js가 있을 때
npx serve .
```

그리고 브라우저에서 `http://localhost:8000` 을 엽니다.

> 태블릿에서 쓰려면 같은 와이파이에 연결한 뒤 컴퓨터의 주소(`http://192.168.0.x:8000`)로 접속하거나,
> GitHub Pages · Netlify · Vercel 같은 곳에 폴더를 그대로 올려서 쓰면 됩니다.
> 서버 코드가 없는 순수 정적 파일이라 어디에 올려도 그대로 동작합니다.

### 3) Gemini API 키 넣기 (선생님)

앱을 처음 열면 홈 화면 아래에 **`🔑 API 키 넣기`** 단추가 보입니다. 이 단추를 누르면
선생님용 설정이 열리고 키 입력칸으로 바로 이동합니다.

> 키를 이미 넣은 뒤에는 이 단추가 사라집니다. 그 뒤에는 **오른쪽 위 톱니바퀴(⚙)를 약 1초간 길게 눌러** 설정을 엽니다.
> (학생이 실수로 열지 않도록 길게 누르기로 되어 있습니다. 키보드에서는 톱니바퀴에 Tab으로 이동한 뒤 Enter를 누르면 바로 열립니다.)

키 발급 방법:

1. [Google AI Studio](https://aistudio.google.com) 에 구글 계정으로 로그인
2. **Get API key → Create API key** 를 눌러 키 생성
3. 만들어진 키를 복사해서 앱의 **Gemini API 키** 칸에 붙여넣고 **저장하기**

- 키는 **이 기기의 브라우저 저장소(localStorage)에만** 저장되며, 코드에 하드코딩되어 있지 않고 다른 서버로 전송되지 않습니다.
- 공용 태블릿이라면 수업이 끝난 뒤 설정에서 **지우기**를 눌러 삭제해 주세요.
- 영상·노래 기능은 결제가 연결된 프로젝트에서만 동작할 수 있습니다.

## 2. 화면 흐름

```
[처음 실행] 안내 4장 (건너뛰기 가능 · 나중에 도움말에서 다시 보기)
        │
      [홈]  5개 카드(각 카드에 한 줄 설명) + 작품 보관함 + 도움말(?) + 선생님용 설정(⚙)
        │
        ├── 그림 / 노래 / 영상 / 그림책
        │      1단계  주제 고르기 (우주 · 바다 · 산 · 하늘)
        │      2~5단계 질문 4개  ← 선택지는 매번 AI가 새로 만듦(실패 시 기본 목록)
        │      (그림책) 몇 장으로 만들지 고르기
        │      6단계  개인화 — 내 그림 첨부(건너뛰기 가능) / 노래는 주인공 이름
        │      7단계  확인 — 고른 것 요약, 줄을 누르면 그것만 다시 고르기
        │      ↓
        │    만드는 중 (천천히 차오르는 물결 애니메이션)
        │      ↓
        │    결과 — 작품 이름 붙이기 · 이야기 읽어주기 · 저장 · 보관함 · 다시 만들기
        │
        └── 내 그림 바꾸기
               1단계  내 그림 올리기 (필수)
               2단계  무엇을 바꿀지 — 색칠하기 / 배경 넣기 / 반짝이게 / 만화처럼
               3단계  확인 → 만드는 중 → 결과
```

모든 화면 위쪽에 **`2/7 단계 — 주인공 고르기`** 처럼 지금 무엇을 하는 중인지 표시되고,
**뒤로** 단추로 언제든 앞 단계로 돌아갈 수 있습니다. 오답·실패 개념은 없습니다.

## 3. 사용하는 모델

| 기능 | 모델 |
|---|---|
| 그림 생성 · 내 그림 바꾸기 | `gemini-3.1-flash-lite-image` |
| 노래 생성 | `lyria-3-clip-preview` |
| 영상 생성 | `veo-3.1-lite-generate-preview` |
| 선택지 생성 · 이야기 문장 · 이름 제안 · 그림 설명 · 프롬프트 다듬기 | `gemini-3.1-flash-lite` |
| 음성 읽어주기 | **API 사용 안 함** — 브라우저 내장 Web Speech API(`speechSynthesis`), 무료 · 오프라인 동작 |

모델 이름은 `js/config.js` 의 `CFG.MODELS` 한 곳에 모아 두었습니다. 나중에 모델이 바뀌면 이 부분만 고치면 됩니다.

### AI가 도와주는 학생 지원 기능

1. **선택지 자동 생성** — 같은 주제를 골라도 매 차시 조금씩 다른 선택지가 나와 반복 수업에도 지루하지 않습니다.
   쉬운 낱말 / 밝고 따뜻한 내용만 / 항목마다 이모지 1개 조건이 프롬프트에 들어 있습니다.
   **호출에 실패하거나 인터넷이 없으면 미리 준비된 기본 선택지로 자동 대체되어 앱이 멈추지 않습니다.**
2. **이야기 문장 만들기** — 고른 것들을 2~3문장의 따뜻한 이야기로 정리해 결과 화면에 보여주고 음성으로 읽어 줍니다.
3. **작품 이름 제안** — 이름 짓기가 어려울 때 3개를 추천합니다.
4. **내 그림 설명받기** — 첨부한 그림을 보고 "이렇게 보여요"라고 이야기해 줍니다.
   화면에 *"정답이 아니라 컴퓨터의 생각이며 내가 그린 뜻과 다를 수 있다"* 고 함께 표시됩니다.
5. **프롬프트 다듬기** — 한국어 선택들을 이미지·영상 모델용 문장으로 바꾸고,
   "밝고 따뜻하며 아동에게 적합한 스타일" 같은 **안전 지시어를 자동으로 덧붙입니다.**

## 4. 영상 하루 사용 횟수 제한

영상 생성은 비용이 가장 크므로 **기기별 하루 사용 횟수 제한**이 들어 있습니다.

- 기본값 **하루 3회**, 선생님용 설정에서 **0~10회** 조절 (0이면 영상 기능 자체가 잠김)
- 홈 화면 영상 카드에 **"오늘 남은 횟수: 2번"** 이 항상 표시됩니다
- 다 쓰면 카드가 비활성화되고 *"오늘 영상은 다 만들었어요. 내일 또 만들어요!"* 라고 부드럽게 안내합니다 (실패·오류처럼 보이지 않게)
- 사용 횟수는 날짜와 함께 localStorage에 저장되고 **날짜가 바뀌면 자동으로 초기화**됩니다
- 설정에 **즉시 초기화** 단추도 있습니다
- 횟수는 **영상 생성이 성공했을 때만** 차감됩니다

> ⚠️ **이것은 비용 관리용 장치이지 보안 장치가 아닙니다.**
> 브라우저 저장소를 지우거나 시크릿 창을 쓰거나 다른 기기를 쓰면 횟수가 초기화됩니다.
> 예산을 엄격히 관리해야 한다면 구글 클라우드 콘솔에서 프로젝트 단위의 결제 한도를 함께 설정해 주세요.

## 6. 접근성 · 안전

- **스위치 스캐닝 모드** — 선택지에 순서대로 보라색 테두리가 들어오고 **스페이스바**로 선택합니다.
  기본 꺼짐이며 선생님이 켭니다. 글자 입력칸을 선택하면 12초간 스캐닝이 멈춥니다.
- **키보드 조작** — Tab · 화살표 · Enter 로 모든 조작이 가능하고, 포커스 표시가 항상 또렷합니다.
- **스크린리더** — 모든 카드·단추·이미지에 라벨이 있고, 단계 변화는 `aria-live` 로 안내됩니다.
- **광과민성 발작 예방** — **초당 3회 이상 깜빡이는 효과가 전혀 없습니다.**
  "만드는 중" 화면도 빠른 회전 대신 9~14초 주기로 천천히 차오르는 물결입니다.
- **부드러운 전환** — 화면 전환은 0.4~0.5초 페이드/슬라이드이며 급격한 명암 변화가 없습니다.
  기기의 "동작 줄이기(prefers-reduced-motion)" 설정을 켜면 애니메이션이 거의 사라집니다.
- **저채도 배경 · 고대비 선택지** — 바탕은 크림색 단색, 카드와 글자는 높은 대비.
- **큰 버튼 · 넓은 간격** — 모든 누를 수 있는 요소는 최소 56px 이상입니다.

## 7. 개인정보

- 그림 첨부 화면에 **"학생 얼굴 사진이나 목소리는 올리지 마세요. 직접 그린 그림만 사용해요"** 안내가 항상 표시됩니다.
- 주인공 이름 입력칸 옆에 **"별명을 써도 좋아요"** 안내가 있습니다.
- 학생이 고른 내용 · 이야기 · 작품 이름 · 작품 파일은 **이 앱의 서버로 전송되지 않습니다** (서버 자체가 없습니다).
  설정은 localStorage에, 작품은 IndexedDB에 저장되어 **기기 안에만** 남습니다.
- 다만 작품을 만들 때 **고른 내용과 첨부한 그림은 구글의 생성 API로 전송**됩니다. 민감한 그림은 올리지 마세요.
- 공용 기기는 수업 후 **보관함 모두 지우기 + API 키 지우기**를 권합니다.

## 8. 작품 보관함

만든 작품을 앱 안에서 다시 볼 수 있습니다.

- 그림·영상·노래는 용량이 크므로 localStorage가 아닌 **IndexedDB**에 Blob으로 저장합니다.
- 작품 이름과 만든 날짜가 함께 표시되고, 개별 **저장(다운로드)** 과 **지우기**를 할 수 있습니다.
- 결과 화면의 **`🗂 보관함에 담기`** 를 눌러야 저장됩니다(자동 저장 아님).

## 9. 파일 구조

```
index.html          화면 뼈대 + 겹침 창(안내 · 도움말 · 설정 · 보관함)
css/style.css       따뜻한 파스텔 테마, 애니메이션, 접근성 스타일
js/config.js        모델 이름 · 기본 설정 · 질문 목록 · 기본 선택지 · 안내 문구
js/store.js         설정 저장(localStorage) · 영상 하루 사용 횟수 · 효과음
js/db.js            작품 보관함(IndexedDB)
js/api.js           Gemini API 호출 (선택지 · 이야기 · 이름 · 그림 · 노래 · 영상)
js/speech.js        읽어주기 (브라우저 speechSynthesis, API 미사용)
js/ui.js            화면 그리기 도우미 · 겹침 창 · 파일 다루기
js/scanning.js      스위치 스캐닝 모드
js/panels.js        처음 안내 · 도움말 · 선생님용 설정 · 보관함 화면
js/app.js           전체 화면 흐름(홈 → 주제 → 질문 → 개인화 → 확인 → 결과)
```

빌드 도구·의존성 없이 브라우저에서 바로 실행되는 순수 HTML/CSS/JS입니다.

## 11. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| "API 키가 올바르지 않아요" | 설정에서 키를 다시 붙여넣기. 앞뒤 공백이 들어가지 않았는지 확인 |
| 선택지가 늘 똑같이 나옴 | 키가 없거나 인터넷이 끊겨 기본 선택지로 대체된 상태입니다 |
| 영상 카드가 잠겨 있음 | 오늘 횟수를 다 썼거나 설정에서 0회로 되어 있습니다 |
| 노래·영상이 만들어지지 않음 | 해당 모델은 결제가 연결된 프로젝트에서만 쓸 수 있습니다 |
| 읽어주기가 안 됨 | 기기 설정에서 한국어 음성이 설치되어 있는지 확인 |
| 보관함에 담기지 않음 | 기기 저장 공간 부족이거나 시크릿 모드일 수 있습니다 |
