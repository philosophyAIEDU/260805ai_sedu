# 내 이야기 만들기 — 재활학교(특수학교) 학생을 위한 AI 창작 웹앱

학생이 **고르기만 하면** 자기 이야기로 그림 · 노래 · 영상 · 그림책 · 이야기가 만들어지는 정적 웹앱입니다.
글을 길게 쓰지 않아도 되고, 모든 단계는 큰 카드를 누르는 "선택"으로 진행됩니다.

📖 **그림책은 AI가 알아서 3~4장을 만들어 주지 않습니다.** 첫 장면을 학생이 넣거나 고르고,
그 뒤로는 **"다음에는 무슨 일이 일어날까요?" 카드를 학생이 눌러** 같은 주인공으로 한 장씩
이야기를 이어 갑니다. → [2-1. 그림책](#2-1--그림책--학생이-다음-이야기를-직접-이어-만듭니다)

## 1. 빠르게 시작하기

### 1) 파일 받기

```bash
git clone <이 저장소 주소>
cd 260805ai_sedu
```

### 2) 실행하기 (로컬 서버 권장)

별도의 서버 프로그램이나 빌드 과정이 필요 없습니다. 다만 브라우저 보안 정책(CORS) 때문에
**`index.html`을 더블클릭해서 여는 방식(`file://`)은 권장하지 않습니다.** 아래처럼 간단한
정적 서버로 열어 주세요. (파이썬은 대부분의 맥/리눅스에 이미 들어 있습니다.)

```bash
# 파이썬이 있을 때
python3 -m http.server 8000

# Node.js가 있을 때
npx serve .
```

그리고 브라우저에서 `http://localhost:8000` 을 엽니다.

> 태블릿에서 쓰려면 같은 와이파이에 연결한 뒤 컴퓨터의 주소(`http://192.168.0.x:8000`)로 접속하거나,
> GitHub Pages · Netlify · Vercel 같은 곳에 폴더를 그대로 올려서 쓰면 됩니다.
> 서버 코드가 없는 순수 정적 파일이라 어디에 올려도 그대로 동작합니다.

### 3) Gemini API 키 넣기 (선생님)

앱을 처음 열면 홈 화면 아래에 **`🔑 API 키 넣기`** 단추가 보입니다. 이 단추를 누르면
선생님용 설정이 열리고 키 입력칸으로 바로 이동합니다.

> 키를 이미 넣은 뒤에는 이 단추가 사라집니다. 그 뒤에는 **오른쪽 위 톱니바퀴(⚙)를 약 1초간 길게 눌러** 설정을 엽니다.
> (학생이 실수로 열지 않도록 길게 누르기로 되어 있습니다. 키보드에서는 톱니바퀴에 Tab으로 이동한 뒤 Enter를 누르면 바로 열립니다.)

키 발급 방법:

1. [Google AI Studio](https://aistudio.google.com) 에 구글 계정으로 로그인
2. **Get API key → Create API key** 를 눌러 키 생성
3. 만들어진 키를 복사해서 앱의 **Gemini API 키** 칸에 붙여넣고 **저장하기**

- 키는 **이 기기의 브라우저 저장소(localStorage)에만** 저장되며, 코드에 하드코딩되어 있지 않고 다른 서버로 전송되지 않습니다.
- 공용 태블릿이라면 수업이 끝난 뒤 설정에서 **지우기**를 눌러 삭제해 주세요.
- 영상·노래 기능은 결제가 연결된 프로젝트에서만 동작할 수 있습니다.

## 2. 화면 흐름

```
[처음 실행] 안내 4장 (건너뛰기 가능 · 나중에 도움말에서 다시 보기)
        │
      [홈]  6개 카드(각 카드에 한 줄 설명) + 다른 앱 링크 + 작품 보관함 + 도움말(?) + 선생님용 설정(⚙)
        │
        ├── 그림 / 노래 / 영상 / 이야기
        │      1단계  주제 고르기 (우주 · 바다 · 산 · 하늘)
        │      2~5단계 질문 4개  ← 선택지는 매번 AI가 새로 만듦(실패 시 기본 목록)
        │      6단계  개인화 — 내 그림 첨부(건너뛰기 가능) / 노래·이야기는 주인공 이름
        │      7단계  확인 — 고른 것 요약, 줄을 누르면 그것만 다시 고르기
        │      ↓
        │    만드는 중 (천천히 차오르는 물결 애니메이션)
        │      ↓
        │    결과 — 작품 이름 붙이기 · 이야기 읽어주기 · 저장 · 보관함 · 다시 만들기
        │
        ├── 그림책 (학생이 한 장씩 이어 만듦 — 아래 2-1 참고)
        │      1~5단계 주제 · 질문 4개
        │      6단계  주인공 이름 짓기 (건너뛰기 가능)
        │      7단계  첫 장면 정하기 — 내 그림 그대로 / 내 그림을 보고 AI가 / AI가 그려줘요
        │      8단계  확인 → 첫 장면 만들기
        │      ↓
        │    그림책 만들기 화면 (반복)
        │      “다음에는 무슨 일이 일어날까요?” 카드 → 같은 주인공으로 다음 장면
        │      ↓
        │    책 완성하기 → 결과
        │
        └── 내 그림 바꾸기
               1단계  내 그림 올리기 (필수)
               2단계  무엇을 바꿀지 — 색칠하기 / 배경 넣기 / 반짝이게 / 만화처럼
               3단계  확인 → 만드는 중 → 결과
```

모든 화면 위쪽에 **`2/7 단계 — 주인공 고르기`** 처럼 지금 무엇을 하는 중인지 표시되고,
**뒤로** 단추로 언제든 앞 단계로 돌아갈 수 있습니다. 오답·실패 개념은 없습니다.

## 2-1. 📖 그림책 — 학생이 다음 이야기를 직접 이어 만듭니다

그림책은 AI가 3~4장을 한 번에 만들어 주지 않습니다. **첫 장면을 학생이 정하고, 그
다음부터는 "이어질 이야기"를 학생이 카드로 골라 한 장씩 늘려 갑니다.** 이야기의 방향을
정하는 사람이 AI가 아니라 학생이 되도록 한 것이 이 기능의 핵심입니다.

**① 첫 장면 정하기** — 세 가지 중에서 고릅니다.

| 고르는 방법 | 1장이 되는 그림 |
|---|---|
| 🖼️ **내 그림 그대로** | 학생이 올린 그림이 **그대로 1장**이 됩니다 (그림 생성 호출 없음) |
| ✨ **AI가 그려줘요** (그림 올린 뒤) | 올린 그림을 **보고** 첫 장면을 그립니다 |
| ✨ **AI가 그려줘요** (그림 없이) | 앞에서 고른 주제·주인공·행동·기분·색으로 그립니다 |

어느 쪽이든 첫 장면을 만들 때 **주인공의 생김새를 영어 한 줄로 받아 둡니다**(`ctx.character`).
내 그림을 그대로 쓸 때는 그 그림을 함께 보내서 **실제로 그린 주인공의 생김새**를 받아 둡니다.

**② 다음 이야기 고르기 → 다음 장면 만들기** (원하는 만큼 반복)

- 화면에 지금까지 만든 장면이 모두 보이고, 아래에 **"다음에는 무슨 일이 일어날까요?"**
  카드가 2~4개 나옵니다. (`"친구를 만나요"`, `"하늘로 올라가요"` 처럼 4~10글자의 쉬운 말)
- 카드는 **지금까지의 줄거리와 주인공을 보고** 매번 새로 만들어집니다. 이미 고른 줄거리는
  다시 나오지 않습니다. (호출 실패·오프라인이면 `CFG.FALLBACK.next` 기본 목록으로 대체)
- 카드를 누르면 그 줄거리대로 **다음 장면의 문장과 그림**이 만들어집니다.

**③ 주인공이 바뀌지 않게 하는 방법**

다음 장면을 그릴 때마다 **바로 앞 장면의 그림을 함께 보내고**, 프롬프트에
`"앞 장면과 똑같은 주인공(생김새 묘사) · 같은 그림체로 다음 장을 그려라"` 를 붙입니다.
그림 + 글 두 가지로 주인공을 붙잡아 두는 방식입니다. (`API.nextScenePrompt`)

**④ 언제든 멈출 수 있습니다**

- **`📚 여기까지! 책 완성하기`** 를 누르면 그때까지 만든 장면이 그대로 그림책이 됩니다
  (최소 1장). 결과 화면에서 이름 붙이기 · 읽어주기 · 저장 · 보관함까지 그대로 됩니다.
- **`↩️ 마지막 장 지우기`** 로 방금 만든 장면만 되돌릴 수 있습니다.
- **`🔁 다른 이야기 보여주세요`** 로 줄거리 카드만 새로 뽑을 수 있습니다.
- 결과 화면에서 **뒤로** 또는 **`📖 더 이어서 만들기`** 를 누르면 다시 이어 만들 수 있습니다.
- 최대 장수는 선생님용 설정에서 **2 / 4 / 6 / 8장**(기본 6장)으로 정합니다.
  **장면 하나마다 그림을 한 장 만들기 때문에** 이 값이 비용과 시간에 그대로 영향을 줍니다.

**⑤ 장면 보기 — 자막과 크게 보기**

- 모든 장면은 그림 아래쪽에 **영화 자막처럼 줄거리 문구**가 겹쳐 표시됩니다.
  **흰 바탕에 검은 글씨**(굵게)라서 그림 색과 상관없이 항상 또렷하게 읽힙니다.
- 장면을 누르면 **크게 보기** 창이 열려 한 컷을 큰 그림과 큰 자막으로 봅니다.
  **`◀ 앞 장면` · `다음 장면 ▶`** (또는 키보드 좌우 화살표)로 한 컷씩 넘겨 보고,
  **`🔊 읽어주기`** 로 그 장면의 문구를 들을 수 있습니다. 첫 장·마지막 장에서는
  넘기는 단추가 비활성화되어 어디까지 왔는지 알 수 있습니다.
- 완성한 뒤 **작품 이름 붙이기 화면**과 **만드는 중 화면(지금까지 만든 장면)** 어디에서나
  같은 방식으로 눌러 볼 수 있습니다.

**⑥ 저장하면 자막까지 그림에 새겨집니다**

화면의 자막은 그림 위에 글자를 얹어 둔 것이라 **그냥 저장하면 파일에는 남지 않습니다.**
그래서 **`📚 여기까지! 책 완성하기`** 를 누를 때 저장용 그림을 따로 만들어
**자막을 그림 안에 직접 그려 넣습니다.** (`UI.captionImage` — 캔버스에 그림을 그린 뒤
아래쪽에 흰 띠와 검은 글씨를 얹어 PNG로 만듭니다. 글자는 그림 너비에 맞춰 줄바꿈하고,
낱말이 반으로 갈리지 않도록 띄어쓰기에서 먼저 자릅니다.)

- **`💾 기기에 내려받기` · `📤 사진에 담기 · 보내기` · `🗂 보관함에 담기`** 모두 자막이 들어간 그림으로 저장됩니다.
- 화면에 보이는 그림은 자막이 두 번 겹치지 않도록 **원래 그림 그대로** 씁니다
  (`result.blobs` = 원본, `result.saveBlobs` = 자막을 새긴 저장용).
- 자막을 새기지 못하는 상황에서도 **원래 그림으로 저장은 그대로 됩니다.**

## 3. 사용하는 모델

| 기능 | 모델 | 호출 방식 |
|---|---|---|
| 그림 생성 · 내 그림 바꾸기 | `gemini-3.1-flash-lite-image` | `generateContent` |
| 노래 생성 | `lyria-3-clip-preview` | `generateContent` (`responseModalities: ["AUDIO","TEXT"]`) |
| 영상 생성 | `veo-3.1-lite-generate-preview` | `predictLongRunning` |
| 선택지 생성 · 이야기 문장 · 이름 제안 · 그림 설명 · 프롬프트 다듬기 · 📝 이야기 만들기 | `gemini-3.1-flash-lite` | `generateContent` |
| 음성 읽어주기 | **API 사용 안 함** — 브라우저 내장 Web Speech API(`speechSynthesis`), 무료 · 오프라인 동작 | — |

모델 이름은 `js/config.js` 의 `CFG.MODELS` 한 곳에 모아 두었습니다. 나중에 모델이 바뀌면 이 부분만 고치면 됩니다.

> **노래 모델은 `predict` 가 아니라 `generateContent` 로 부릅니다.**
> `predict` 로 부르면 `models/lyria-3-clip-preview is not found for API version v1beta,
> or is not supported for predict.` 라는 **404** 가 납니다. 모델은 있는데 그 방식을 받지
> 않는다는 뜻입니다. 소리는 응답의 `inlineData` 로 오고, 껍데기 없는 PCM(`audio/L16`)
> 으로 올 때는 앱이 WAV로 감싸 재생·저장할 수 있게 만듭니다.

### 모델을 못 찾으면(404) 자동으로 바꿔 씁니다

쓸 수 있는 모델 이름은 계정·지역·시기에 따라 다릅니다. 그래서 `CFG.MODELS` 의 이름이
404가 나면, 앱이 **모델 목록을 조회해 같은 종류의 모델로 한 번 바꿔서 다시 시도**합니다.
후보 순서는 `js/config.js` 의 `CFG.MODEL_FALLBACKS` 에 적혀 있습니다.
(목록 조회는 생성 요청이 아니라 **비용이 들지 않습니다.**)

무엇으로 바꿔 쓰는지는 **설정 → “🔍 이 키로 무엇을 쓸 수 있는지 확인하기”** 에서 볼 수
있고, 실패했을 때는 오류 화면의 **“선생님께 — 자세한 내용 보기”** 에 이 키로 보이는
비슷한 모델 이름이 함께 표시됩니다.

### AI가 도와주는 학생 지원 기능

1. **선택지 자동 생성** — 같은 주제를 골라도 매 차시 조금씩 다른 선택지가 나와 반복 수업에도 지루하지 않습니다.
   쉬운 낱말 / 밝고 따뜻한 내용만 / 항목마다 이모지 1개 조건이 프롬프트에 들어 있습니다.
   **호출에 실패하거나 인터넷이 없으면 미리 준비된 기본 선택지로 자동 대체되어 앱이 멈추지 않습니다.**
2. **이야기 문장 만들기** — 고른 것들을 2~3문장의 따뜻한 이야기로 정리해 결과 화면에 보여주고 음성으로 읽어 줍니다.
3. **작품 이름 제안** — 이름 짓기가 어려울 때 3개를 추천합니다.
4. **내 그림 설명받기** — 첨부한 그림을 보고 "이렇게 보여요"라고 이야기해 줍니다.
   화면에 *"정답이 아니라 컴퓨터의 생각이며 내가 그린 뜻과 다를 수 있다"* 고 함께 표시됩니다.
5. **프롬프트 다듬기** — 한국어 선택들을 이미지·영상 모델용 문장으로 바꾸고,
   "밝고 따뜻하며 아동에게 적합한 스타일" 같은 **안전 지시어를 자동으로 덧붙입니다.**
6. **그림책 — 이어질 줄거리 카드** — 지금까지의 줄거리를 보고 "다음에 무슨 일이 일어날까"
   후보를 만들어 줍니다. **고르는 사람은 학생이고, AI는 고를 것만 준비합니다.**
   같은 주인공이 이어지도록 주인공 생김새와 앞 장면 그림을 매번 함께 보냅니다. (→ 2-1)

## 3-1. 무료 API 키로 쓰기 — 📝 이야기 만들기

무료 등급 키는 **글자 모델은 잘 되지만 그림·노래·영상 모델은 할당량이 없거나 아주 적어** 429(한도 초과)가 나기 쉽습니다.
그래서 글자 모델만 사용하는 **📝 이야기 만들기** 를 넣었습니다.

- 주제와 질문을 똑같이 고르고, 마지막에 **이야기 문장 + 읽어주기 + 작품 이름 + 보관함 저장**까지 그대로 됩니다.
- 그림을 만들지 않으므로 무료 키로도 잘 동작하고 비용이 가장 적습니다.
- 결과는 `.txt` 파일로 저장됩니다.

### 내 키로 무엇을 쓸 수 있는지 확인하기

선생님용 설정의 API 키 칸 아래 **`🔍 이 키로 무엇을 쓸 수 있는지 확인하기`** 를 누르면
글자 / 그림 / 노래 / 영상 각각에 ✅ · ❌ 가 표시됩니다.

- 모델 목록 조회는 생성 요청이 아니라 **비용이 들지 않습니다.** 글자 모델만 아주 짧게 한 번 호출해 한도까지 확인합니다.
- ❌ 가 있으면 **`표시된 기능 끄기`** 로 한 번에 꺼서, 학생이 눌렀다가 실패하는 일을 막을 수 있습니다.
- 모두 꺼도 📝 이야기 만들기는 남으므로 수업을 그대로 진행할 수 있습니다.

## 4. 영상 하루 사용 횟수 제한

영상 생성은 비용이 가장 크므로 **기기별 하루 사용 횟수 제한**이 들어 있습니다.

- 기본값 **하루 3회**, 선생님용 설정에서 **0~10회** 조절 (0이면 영상 기능 자체가 잠김)
- 홈 화면 영상 카드에 **"오늘 남은 횟수: 2번"** 이 항상 표시됩니다
- 다 쓰면 카드가 비활성화되고 *"오늘 영상은 다 만들었어요. 내일 또 만들어요!"* 라고 부드럽게 안내합니다 (실패·오류처럼 보이지 않게)
- 사용 횟수는 날짜와 함께 localStorage에 저장되고 **날짜가 바뀌면 자동으로 초기화**됩니다
- 설정에 **즉시 초기화** 단추도 있습니다
- 횟수는 **영상 생성이 성공했을 때만** 차감됩니다

> ⚠️ **이것은 비용 관리용 장치이지 보안 장치가 아닙니다.**
> 브라우저 저장소를 지우거나 시크릿 창을 쓰거나 다른 기기를 쓰면 횟수가 초기화됩니다.
> 예산을 엄격히 관리해야 한다면 구글 클라우드 콘솔에서 프로젝트 단위의 결제 한도를 함께 설정해 주세요.

## 6. 접근성 · 안전

- **고를 것을 읽어 줍니다 (글자를 읽기 어려운 학생용)** — 홈·주제·질문 화면의 카드마다
  오른쪽 위에 작은 **🔊** 단추가 있어, 누르면 그 낱말("우주", "바다", "하늘" …)을 읽어 줍니다.
  카드 아래 **`🔊 하나씩 읽어주기`** 를 누르면 질문과 선택지를 **차례로** 읽어 주고,
  **`⏹ 그만 듣기`** 로 멈춥니다. 카드 본체를 눌러야 선택되고, 🔊 를 눌러도 화면이 넘어가지
  않습니다. 브라우저 내장 음성이라 **비용이 들지 않고 인터넷이 없어도 됩니다.**
  (스위치 스캐닝에서는 고를 것이 두 배로 늘지 않도록 🔊 단추를 차례에서 제외합니다.)
- **스위치 스캐닝 모드** — 선택지에 순서대로 보라색 테두리가 들어오고 **스페이스바**로 선택합니다.
  기본 꺼짐이며 선생님이 켭니다. 글자 입력칸을 선택하면 12초간 스캐닝이 멈춥니다.
- **키보드 조작** — Tab · 화살표 · Enter 로 모든 조작이 가능하고, 포커스 표시가 항상 또렷합니다.
- **스크린리더** — 모든 카드·단추·이미지에 라벨이 있고, 단계 변화는 `aria-live` 로 안내됩니다.
- **광과민성 발작 예방** — **초당 3회 이상 깜빡이는 효과가 전혀 없습니다.**
  "만드는 중" 화면도 빠른 회전 대신 9~14초 주기로 천천히 차오르는 물결입니다.
- **부드러운 전환** — 화면 전환은 0.4~0.5초 페이드/슬라이드이며 급격한 명암 변화가 없습니다.
  기기의 "동작 줄이기(prefers-reduced-motion)" 설정을 켜면 애니메이션이 거의 사라집니다.
- **저채도 배경 · 고대비 선택지** — 바탕은 크림색 단색, 카드와 글자는 높은 대비.
- **큰 버튼 · 넓은 간격** — 모든 누를 수 있는 요소는 최소 56px 이상입니다.

  설정은 localStorage에, 작품은 IndexedDB에 저장되어 **기기 안에만** 남습니다.
- 다만 작품을 만들 때 **고른 내용과 첨부한 그림은 구글의 생성 API로 전송**됩니다. 민감한 그림은 올리지 마세요.
- 공용 기기는 수업 후 **보관함 모두 지우기 + API 키 지우기**를 권합니다.

## 8. 작품 보관함

만든 작품을 앱 안에서 다시 볼 수 있습니다.

- 그림·영상·노래는 용량이 크므로 localStorage가 아닌 **IndexedDB**에 Blob으로 저장합니다.
- 작품 이름과 만든 날짜가 함께 표시되고, 개별 **내려받기**·**보내기**·**지우기**를 할 수 있습니다.
- 결과 화면의 **`🗂 보관함에 담기`** 를 눌러야 저장됩니다(자동 저장 아님).

### 저장한 그림이 어디에 있는지 알려 줍니다

“저장했는데 어디에 있는지 모르겠다”는 말이 가장 많았습니다. 그래서 저장 방법을 세 가지로
나누고, 누른 뒤에 **어디로 갔는지 화면에 바로 알려 줍니다.**

| 단추 | 하는 일 | 눌렀을 때 나오는 안내 |
|---|---|---|
| 💾 **기기에 내려받기** | 파일로 내려받기 | 「작품이름.png」 이름과 함께, 그 기기에서 찾아갈 곳(아이패드 = 파일 앱 → 다운로드, 안드로이드 = 내 파일 → Download, 컴퓨터 = 다운로드 폴더) |
| 📤 **사진에 담기 · 보내기** | 사진 앱·다른 앱으로 바로 보내기 (`navigator.share`, 지원하는 기기에서만 표시) | “이미지 저장”을 고르면 사진 앱(갤러리)에 들어간다는 안내 |
| 🗂 **보관함에 담기** | 이 앱 안에 모아 두기 | 앱의 “작품 보관함”에서 다시 볼 수 있고 기기 밖으로 나가지 않는다는 안내 |

그림·그림책 결과에는 “그림을 길게 누르면 **이미지 저장**으로도 사진 앱에 담을 수 있어요”
라는 안내가 함께 붙습니다. 보관함에서도 같은 방식으로 안내합니다.

## 11. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| "API 키가 올바르지 않아요" | 설정에서 키를 다시 붙여넣기. 앞뒤 공백이 들어가지 않았는지 확인 |
| **"지금은 쉬어야 해요" (콘솔에 429)** | **키 문제가 아니라 요청 한도 초과입니다.** 무료 등급의 분당·하루 한도를 넘었거나, 해당 모델에 결제가 연결되어 있지 않은 경우입니다. 앱이 8초·20초 간격으로 자동 재시도하고, 그래도 안 되면 오류 화면 아래 **"선생님께 — 자세한 내용 보기"** 에 실제 응답이 표시됩니다. 1~2분 뒤 재시도하거나 결제 연결을 확인해 주세요. 키가 잘못된 경우에는 429가 아니라 400·403이 뜹니다 |
| 선택지가 늘 똑같이 나옴 | 키가 없거나 인터넷이 끊겨 기본 선택지로 대체된 상태입니다 |
| 영상 카드가 잠겨 있음 | 오늘 횟수를 다 썼거나 설정에서 0회로 되어 있습니다 |
| 노래·영상이 만들어지지 않음 | 해당 모델은 결제가 연결된 프로젝트에서만 쓸 수 있습니다 |
| **"모델을 찾지 못했습니다 (404)"** | 모델 이름이 없거나, 그 모델이 그 호출 방식을 받지 않는 경우입니다. 앱이 이 키로 쓸 수 있는 같은 종류의 모델로 **한 번 자동으로 바꿔** 시도하고, 그래도 안 되면 오류 화면의 **"선생님께 — 자세한 내용 보기"** 에 **이 키로 보이는 비슷한 모델 이름**을 보여 줍니다. 그중 하나를 `js/config.js` 의 `CFG.MODELS` 에 적어 주세요 |
| **저장한 그림이 어디 있는지 모르겠음** | **`💾 기기에 내려받기`** 를 누르면 파일 이름과 저장된 폴더를 화면에 알려 줍니다. 태블릿에서는 **`📤 사진에 담기 · 보내기`** → "이미지 저장" 이 가장 쉽습니다. 그림을 **길게 눌러** "이미지 저장" 을 해도 됩니다 |
| 읽어주기가 안 됨 | 기기 설정에서 한국어 음성이 설치되어 있는지 확인 |
| 보관함에 담기지 않음 | 기기 저장 공간 부족이거나 시크릿 모드일 수 있습니다 |
